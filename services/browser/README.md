# JobPilot - Browser Automation Service

## Status: Intentionally Deferred (Phase 2A)

This directory is reserved for browser automation adapters and session management (e.g., Playwright automation).

### Future Responsibilities

- Secure portal adapters (LinkedIn, Naukri, Indeed, Wellfound, Hirist, Unstop, ATS portals)
- Form detection, field autofill, and application submission verification
- Sandbox isolation between untrusted portal web contexts and local application privileges

### Phase 2A Constraint

No Playwright dependencies, browser sessions, scrapers, or automation scripts are implemented during Phase 2A.
